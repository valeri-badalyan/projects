# V3AI для PowerShell

Консольная версия ИИ-помощника V3AI — **«V3AI Terminal»**: неоновый логотип, цветные ответы с подсветкой кода, рамки-карточки и строка ввода, в которой всегда видно модель и режим:

```

  ██║   ██║ █████╔╝███████║██║
  ╚██╗ ██╔╝ ╚═══██╗██╔══██║██║
   ╚████╔╝ ██████╔╝██║  ██║██║
    ╚═══╝  ╚═════╝ ╚═╝  ╚═╝╚═╝
  Terminal  v1.0 · ИИ-помощник от команды V3

[V3 ORTL 5.5 · ✨ Помощник] ❯ Объясни, что такое рекурсия
```

Один файл — `v3ai.ps1`, без установки модулей. Работает в **Windows PowerShell 5.1** и **PowerShell 7** (Windows, macOS, Linux). Для цветного градиента и эмодзи лучше всего подходит Windows Terminal.

## Установка одной строкой

Вставьте в PowerShell (Windows, macOS или Linux):

```powershell
irm https://raw.githubusercontent.com/valeri-badalyan/projects/ccr-617a6cca-m3ccsg/v3ai/powershell/install.ps1 | iex
```

Установщик скачает V3AI в `~/.v3ai/bin`, по вашему согласию добавит команду `v3ai` и предложит сразу запустить программу. Права администратора не нужны. Потом V3AI запускается из любой папки командой `v3ai`.

## Запуск вручную

1. Скачайте `v3ai.ps1`:
   ```powershell
   irm https://raw.githubusercontent.com/valeri-badalyan/projects/ccr-617a6cca-m3ccsg/v3ai/powershell/v3ai.ps1 -OutFile v3ai.ps1
   ```
2. Запустите:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\v3ai.ps1     # Windows PowerShell 5.1
   pwsh ./v3ai.ps1                                         # PowerShell 7
   pwsh ./v3ai.ps1 -Model ards45 -Mode code                # сразу нужная модель и режим
   ```
3. Ключ Claude API: V3AI берёт его из переменной `ANTHROPIC_API_KEY`, а если её нет — попросит вставить ключ при запуске (и может сохранить его). Ключ создаётся на https://platform.claude.com. Без ключа работает небольшой офлайн-режим: примеры, время, шутки, загадки.

Запросы к Claude оплачиваются с вашего ключа API.

## Что умеет

| Режим | Команда | Что делает |
|---|---|---|
| ✨ Помощник | `/mode help` | Ответы на любые вопросы |
| 📚 Учёба | `/mode school` | Объясняет шаг за шагом |
| ✍ Писатель | `/mode write` | Истории, стихи, поздравления |
| 🌍 Переводчик | `/mode lang` | Перевод и произношение |
| 💻 Код | `/mode code` | Пишет и объясняет код |
| 😂 Весельчак | `/mode fun` | Шутки, загадки, викторины |
| 🎨 Художник | `/mode art` | Рисует SVG-картинку и открывает её |
| 🕹 WattAI | `/mode game` | Пишет браузерную игру (HTML) и открывает её; правки — следующим сообщением |
| ✒ Design | `/mode design` | Рисует 3 варианта логотипа: страница с фоном (светлый, тёмный, шахматка), PNG с прозрачным фоном и SVG |
| 🎬 Видео | `/mode video` | Снимает 3D-мультфильм (или рисованный 2D) и открывает его в плеере |
| 🩺 Dr. Agents | `/mode agents` | Создаёт ИИ-агентов с навыками |

Ответы печатаются по мере написания. **Esc** или **Ctrl+C** во время ответа — остановить. Строка с `\` в конце продолжает ввод на следующей строке.

### Быстрые команды

| Команда | Что делает |
|---|---|
| `/image <описание>` | Создать картинку (SVG) — сразу, в любом режиме |
| `/video <сюжет>` | Снять 3D-видео; `/video 2d <сюжет>` — рисованный 2D-мультик |
| `/watt <описание>` | WattAI: сделать игру |
| `/design <описание>` | V3AI Design: 3 варианта логотипа (то же — `/logo`); доработка: «доработай вариант 2: сделай синим» |
| `/gif <описание>` | Анимированный GIF: откроется страница с анимацией и кнопкой «Скачать GIF» |
| `/photo <файл> [вопрос]` | Спросить ИИ о фото (JPG, PNG, GIF, WEBP до 5 МБ) |
| `/again` | Ещё вариант последнего запроса |
| `/say` | Озвучить последний ответ (`/say stop` — замолчать) |
| `/copy` | Скопировать последний ответ |

Без описания команда просто включает нужный режим.

### Как снимается видео

ИИ пишет сценарий из 3–4 сцен, потом **все сцены рисуются одновременно**. V3AI собирает из них страницу-плеер (`~/.v3ai/video/…html`) на видеодвижке веб-версии и открывает её в браузере. В плеере:

- **▶ Смотреть** — фильм с субтитрами, переходами и музыкой;
- **💾 Скачать видео** — собирает MP4 (720×720) прямо в браузере, быстрее, чем длится ролик.

Для 3D-сцен и быстрой сборки MP4 плееру нужен интернет (он загружает Three.js и упаковщик MP4). Лучше всего плеер работает в Chrome или Edge.

Если в игре WattAI случится ошибка, игра сама покажет её внизу экрана с готовой командой: `/watt исправь ошибку: …`.

Голосовой ввод (микрофон) есть только в веб-версии V3AI.

## Агенты (Dr. Agents)

В режиме `/mode agents` опишите помощника («репетитор английского, который проверяет слова») — Dr. Agents придумает имя, характер, инструкции и навыки. Навыки — настоящие инструменты, которые агент вызывает сам:

🧠 память о вас · ✅ список дел · 🧮 калькулятор · 🕐 дата и время · 🎲 случайности

`/agents` — список, `/agent 1` — чат с агентом, `/agent 1 memory` — его память, `/agent 1 forget` — очистить память, `/agent 1 edit говори стихами` — изменить агента, `/agent 1 delete` — удалить. Память агентов хранится в `~/.v3ai/agent-memory`.

## GitHub

Вставьте в чат ссылку на репозиторий (`https://github.com/владелец/репо`) — V3AI покажет карточку (описание, звёзды, файлы, README, последние коммиты) и дальше отвечает на вопросы о проекте, сам читая папки, файлы, коммиты, ветки, issues и pull requests. Можно сразу со ссылкой задать вопрос в том же сообщении.

- Публичные репозитории открываются без входа (лимит GitHub — 60 запросов в час).
- Для закрытых репозиториев и лимита 5000 в час: `/github login`. Если установлен GitHub CLI (`gh`), токен берётся из него; иначе вставьте fine-grained токен с доступом **Contents: Read-only**. Токен также читается из переменной `GITHUB_TOKEN`.
- Проводник: `/files [папка]` — список файлов, `/cat <файл>` — показать файл с номерами строк.
- Только чтение: V3AI ничего не меняет в репозитории. `/repo` — карточка, `/disconnect` — отключить.

## EngineSecure

Перед потенциально опасными действиями V3AI спрашивает разрешение: **[Д]а один раз · [В]сегда · [Н]ет · [З]апретить навсегда**.

| Действие | Когда спрашивает |
|---|---|
| 🕹 Открытие файлов | перед открытием игры, картинки или видео в браузере |
| 💾 Сохранение файлов | перед записью игр, картинок, видео и экспорта чатов |
| 🐙 Доступ к GitHub | перед подключением репозитория и входом |
| 📷 Отправка фото ИИ | перед отправкой фото командой `/photo` |
| 🔑 Сохранение ключей | перед записью ключа API или токена GitHub в переменные среды |

`/secure` — посмотреть, `/secure 1 allow|ask|deny` — изменить, `/secure off` — выключить защиту (с подтверждением).

## Где хранятся данные

Всё лежит в папке `~/.v3ai` (на Windows — `C:\Users\<имя>\.v3ai`): настройки, история чатов, агенты и их память, созданные игры (`games`), картинки (`art`), логотипы (`design`), GIF (`gif`), видео (`video`) и экспорт чатов (`export`).
