# FDM1 Games

Сайт игровой студии FDM1 Games: каталог игр с фильтрами, новости, форма связи и встроенная мини-игра **Neon Dodge**.

## Запуск

Откройте `index.html` в браузере — сборка не нужна.

## Файлы

- `index.html` — разметка страницы
- `styles.css` — стили (неоновая тема, адаптив под телефоны)
- `script.js` — каталог игр, анимации и мини-игра
